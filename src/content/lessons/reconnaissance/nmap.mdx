**nmap** (*Network Mapper*) adalah alat scanning paling terkenal di dunia, dipakai oleh admin jaringan, auditor, dan pentester. Kamu sudah mengenal semua fondasinya — ARP, ICMP, TCP handshake, RST — dan nmap hanya memanfaatkan perilaku itu secara sistematis.

## 1. Host discovery: siapa yang hidup?

```bash
sudo nmap -sn 10.10.10.0/24
```

`-sn` = hanya cari host, tanpa port scan. Caranya bergantung pada lokasi target:

- **Satu LAN (dengan sudo)** → kirim **ARP request** ke setiap alamat. Tidak bisa diblokir firewall IP, karena ARP bekerja di Layer 2! Tanpa sudo, nmap hanya bisa mencoba koneksi TCP biasa ke port 80/443.
- **Jaringan lain** → ICMP echo, TCP SYN ke port 443, TCP ACK ke port 80, dll.

### Connect scan (`-sT`, default tanpa sudo)

nmap menyelesaikan three-way handshake penuh memakai fungsi biasa sistem operasi. Lebih lambat dan lebih mudah tercatat di log aplikasi, tapi tidak butuh hak root.

### UDP scan (`-sU`)

Lebih lambat dan kurang pasti: port tertutup dijawab ICMP *port unreachable*, sedangkan port terbuka sering diam saja → hasil `open|filtered`.

## Status port

| Status | Artinya | Respons yang diterima |
|---|---|---|
| **open** | ada layanan yang mendengarkan | SYN-ACK |
| **closed** | host hidup, tidak ada layanan | RST |
| **filtered** | firewall menghalangi, status tidak diketahui | tidak ada jawaban / ICMP unreachable |

## 3. Opsi penting

```bash
nmap 10.0.0.5               # scan ~1000 port paling umum
nmap -p 22,80,443 10.0.0.5  # port tertentu
nmap -p- 10.0.0.5           # SEMUA 65535 port
nmap -sV 10.0.0.5           # deteksi versi layanan
sudo nmap -O 10.0.0.5       # tebak sistem operasi
sudo nmap -A 10.0.0.5       # agresif: -sV -O + lainnya (butuh sudo karena ada -O)
nmap -Pn 10.0.0.5           # lewati host discovery (jika ping diblokir)
```

<Callout type="tip" title="Scan default tidak memeriksa semua port">
Tanpa `-p-`, nmap hanya memeriksa sekitar 1000 port terpopuler. Layanan yang berjalan di port "aneh" (misalnya 31337) akan terlewat. Admin kadang mengira memindahkan layanan ke port tinggi membuatnya aman — padahal tidak!
</Callout>

## Membaca hasil

```text
PORT     STATE  SERVICE  VERSION
22/tcp   open   ssh      OpenSSH 7.6p1 Ubuntu 4ubuntu0.7
445/tcp  open   microsoft-ds  Samba smbd 4.7.6-Ubuntu
```

Versi software adalah informasi emas: penyerang mencocokkannya dengan database celah publik (CVE). Bagi pembela, ini daftar **apa yang harus segera di-update**.

## Dari sisi pembela

- Port scan meninggalkan jejak: banyak SYN dari satu IP ke banyak port dalam waktu singkat → mudah dideteksi IDS
- Tutup port yang tidak dipakai, pasang firewall *default deny* (Modul 13)
- Sembunyikan atau minimalkan banner versi
- Lakukan scan terhadap jaringan sendiri secara rutin
