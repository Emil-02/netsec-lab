**Sniffing** adalah menangkap dan membaca paket yang lewat di jaringan. Bagi admin, ini alat diagnosis yang luar biasa. Bagi penyerang, ini cara mencuri data yang dikirim tanpa enkripsi.

## Promiscuous mode

Normalnya, kartu jaringan **membuang** frame yang MAC tujuannya bukan miliknya (ingat tanda ✕ di peta lab). Dalam **promiscuous mode**, kartu jaringan menerima **semua** frame yang sampai kepadanya. Alat sniffing seperti `tcpdump` dan Wireshark mengaktifkan mode ini — karena itu butuh hak root.

## Apa yang bisa disadap?

| Jaringan | Yang terlihat oleh sniffer |
|---|---|
| **Hub** | semua lalu lintas semua perangkat |
| **Switch** | hanya lalu lintas milik sendiri + broadcast (ARP, DHCP) |
| **Wi-Fi terbuka** | semua lalu lintas di udara (tanpa enkripsi Wi-Fi) |

Switch mempersulit sniffing, tapi tidak membuatnya mustahil — penyerang bisa memakai **ARP spoofing** (materi berikutnya) atau **MAC flooding** (Modul 5) untuk menarik lalu lintas ke dirinya.

## tcpdump

```bash
sudo tcpdump -i eth0                  # semua paket di eth0
sudo tcpdump arp                      # hanya ARP
sudo tcpdump icmp                     # hanya ping
sudo tcpdump tcp port 80              # hanya HTTP
sudo tcpdump host 10.0.0.5            # hanya paket dari/ke 10.0.0.5
sudo tcpdump -A tcp port 80           # tampilkan isi paket sebagai teks
sudo tcpdump -c 10                    # berhenti setelah 10 paket
```

Contoh output:

```text
10:00:02.820000 IP 10.3.0.21.51235 > 10.3.0.80.80: Flags [S], seq 0, length 0
10:00:05.720000 IP 10.3.0.21.51235 > 10.3.0.80.80: Flags [P.], seq 1, ack 1, length 174: HTTP: POST /login HTTP/1.1
```

`[S]` = SYN, `[S.]` = SYN-ACK, `[.]` = ACK, `[P.]` = PSH-ACK (data), `[F.]` = FIN-ACK, `[R]` = RST. Titik (`.`) selalu berarti flag ACK ikut menyala.

## Protokol yang berbahaya disadap

Protokol lama mengirim semuanya, termasuk password, sebagai **teks biasa**:

| Protokol tidak aman | Pengganti yang aman |
|---|---|
| HTTP (80) | **HTTPS** (443) |
| Telnet (23) | **SSH** (22) |
| FTP (21) | **SFTP** / FTPS |
| POP3/IMAP tanpa TLS | POP3S / IMAPS |
