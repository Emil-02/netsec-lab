Password masih menjadi pintu utama hampir semua sistem — dan juga titik terlemahnya. Laporan insiden keamanan dari tahun ke tahun menunjukkan bahwa kredensial yang lemah atau bocor adalah salah satu penyebab pembobolan paling umum.

## Dua jenis serangan password

### 1. Online — menebak langsung ke layanan

Penyerang mencoba login berulang kali ke layanan yang hidup (SSH, form login web, RDP).

- **Brute force** — mencoba semua kombinasi (`aaaa`, `aaab`, …). Sangat lambat untuk password panjang.
- **Dictionary attack** — mencoba daftar password populer (`123456`, `password`, `qwerty`…).
- **Credential stuffing** — memakai pasangan email+password yang bocor dari situs lain. Berhasil karena orang memakai ulang password!
- **Password spraying** — mencoba **satu** password umum (misal `Musim2026!`) ke **banyak** akun, agar tidak memicu penguncian akun.

Ciri khasnya mudah terlihat di log:

```text
Failed password for root from 203.0.113.66 port 40100 ssh2
Failed password for admin from 203.0.113.66 port 40102 ssh2
Failed password for invalid user test from 203.0.113.66 port 40104 ssh2
```

### 2. Offline — memecahkan hash yang bocor

Jika database bocor, penyerang mendapat **hash** password. Ia tidak perlu lagi menghubungi server: cukup menghitung hash dari jutaan tebakan di komputernya sendiri dan mencocokkan hasilnya. Tidak ada batas percobaan, tidak ada log!

```text
md5("sayang123") = cocok dengan hash milik budi → password ditemukan
```

## Kenapa MD5 tanpa salt berbahaya?

1. **Terlalu cepat** — GPU modern bisa menghitung miliaran hash MD5 per detik
2. **Tanpa salt** — password yang sama selalu menghasilkan hash yang sama, sehingga penyerang bisa memakai tabel hash yang sudah dihitung sebelumnya (*rainbow table*), dan satu kali crack membuka semua akun dengan password yang sama

**Salt** adalah nilai acak unik per user yang digabung dengan password sebelum di-hash. Dua user dengan password sama akan punya hash berbeda.

Cara yang benar menyimpan password: algoritma yang **sengaja lambat** dan memakai salt, seperti **bcrypt**, **scrypt**, atau **Argon2**.

## Password yang kuat

| Lemah ❌ | Kuat ✅ |
|---|---|
| `sayang123`, `admin123`, `qwerty` | `Kucing-Lompat-Pagar-9` (passphrase panjang) |
| nama + tanggal lahir | dibuat acak oleh **password manager** |
| sama untuk semua akun | **unik** untuk setiap akun |

Panjang lebih penting daripada kerumitan: setiap karakter tambahan melipatgandakan jumlah kemungkinan.

## Pertahanan

- 🔐 **Multi-Factor Authentication (MFA)** — password bocor saja tidak cukup untuk masuk
- 🔁 **Rate limiting & penguncian akun** — batasi percobaan login gagal
- 🚫 **Blokir IP penyerang** — otomatis dengan **fail2ban** (Modul 13)
- 🔑 **SSH dengan kunci publik** — matikan login password untuk SSH
- 🧂 **Simpan password dengan bcrypt/Argon2 + salt**
- 📋 **Tolak password yang ada di daftar bocoran** saat pendaftaran
- 👀 **Pantau log** untuk pola percobaan login gagal
