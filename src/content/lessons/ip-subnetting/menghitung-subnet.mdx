Subnetting adalah **memecah satu jaringan besar menjadi beberapa jaringan kecil** (subnet). Tujuannya: efisiensi alamat, performa, dan — yang penting — **keamanan** melalui segmentasi.

## Empat hal yang harus bisa kamu hitung

Untuk sebuah IP dan prefix, cari:

1. **Alamat network** — alamat pertama (semua bit host = 0)
2. **Alamat broadcast** — alamat terakhir (semua bit host = 1)
3. **Host pertama & terakhir** — rentang yang bisa dipakai perangkat
4. **Jumlah host valid**

## Cara cepat: metode "block size"

Contoh: **`192.168.10.77/26`**

**Langkah 1** — Tentukan oktet yang "menarik". /26 berarti mask `255.255.255.192`. Oktet yang bukan 255 dan bukan 0 adalah oktet ke-4 (nilai **192**).

**Langkah 2** — Hitung **block size** = 256 − 192 = **64**. Subnet-nya akan berkelipatan 64: `.0`, `.64`, `.128`, `.192`.

**Langkah 3** — Cari blok yang memuat **77**: 77 ada di antara 64 dan 128.

**Langkah 4** — Tulis hasilnya:

| | Nilai |
|---|---|
| Alamat network | `192.168.10.64` |
| Host pertama | `192.168.10.65` |
| Host terakhir | `192.168.10.126` |
| Broadcast | `192.168.10.127` |
| Jumlah host | 2⁶ − 2 = **62** |

Bayangkan kantor yang memisahkan jaringan **staf**, **tamu Wi-Fi**, dan **server** ke subnet berbeda. Jika laptop tamu terinfeksi malware, ia tidak bisa langsung menjangkau server karena lalu lintasnya harus melewati router/firewall yang bisa memblokirnya.
