# Security Policy

`netsec-lab` menyimulasikan jaringan sepenuhnya di browser. Tidak ada VM, container, kredensial, atau trafik jaringan nyata yang dipakai aplikasi ini. Flag CTF disimpan sebagai hash SHA-256, dan skrip di tab browser dijalankan di iframe sandbox dengan CSP.

## Melaporkan kerentanan

Sebaiknya jangan buka issue publik. Kirim laporan lewat [GitHub Security Advisories](https://github.com/Emil-02/netsec-lab/security/advisories/new) supaya detailnya tetap privat. Saya biasanya merespons dalam 7 hari.

## Dukungan

Rilis `0.1.x` masih saya dukung dengan perbaikan keamanan.
